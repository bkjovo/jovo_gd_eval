## Three design decisions

**1. Homographs, not homophones.** The brief said "homophones," but homophones
(heel/heal) stress speech-*to*-text: they only matter when you have to choose a spelling.
Text-to-speech is stressed by **homographs / heteronyms** — same spelling, different
pronunciation by context (English *read* /rɛd/ vs /riːd/, *lead* /liːd/ vs /lɛd/). Those
are what the two `homograph` items test.

**2. 23 of 25 items are true parallel translations; 2 are not.** A homograph is
language-specific and does not survive translation, so the two homograph items
(`health-04`, `game-06`) carry a different sentence per language, each testing that
language's own tricky word (fr *fils*/*content*, de *umfahren*, pt *sede*/*colher*).
**Spanish has almost no pronunciation-divergent homographs** — it is phonetically regular —
so its two homograph slots fall back to a hard clinical term and a hard invented proper
noun, noted per row. These rows have `parallel: false`.

**3. Locale formatting is applied, on purpose.** Numbers, currency, dates and times are
written the way each language writes them (`4,250.75` → `4.250,75` → `4 250,75`; 12-hour →
24-hour; `ATM` → `multibanco` in European Portuguese). The divergence is itself a
realistic stress test, not a parallelism break.

## Stress coverage

numbers+units · currency · decimals · URLs · email-style paths · acronyms (localized) ·
alphanumeric codes · digit strings · phone numbers · dates/times · proper nouns · invented
fantasy names · loanwords / code-switching · percentages · ALL-CAPS emphasis · long
multi-clause prosody · very short utterances · homographs.

## Length

Capped so the longest language (French/German here) stays under 20 s — the longest clip
is ~17.9 s, with ~2 s of margin. Spread runs ~2–18 s (median ~3.4 s): mostly realistic
conversational turns, plus one long-form item per domain for sustained prosody.

## Caveats before a paid run

- **Translations want a native pass**, especially the homograph substitutions, the medical
  terminology, and idiomatic domain phrasing. They were authored carefully but not
  natively reviewed.
- **Voices are persona-matched** (see `../voices.json`): all five are current-generation,
  masculine, adult, native-region, primary persona "Neutral/Informational" — Steven (gb),
  Miguel (es), Romain (fr), David (de), Rodrigo (pt). Validate `f0_semitone_std` parity
  across languages after generation; a large outlier means a voice's tags did not match
  its actual delivery and it should be swapped.
- **`run_batch.py` is now incremental.** Point it at this manifest with a fresh out-dir:
  `--manifest corpus/manifest_125.jsonl --out-dir corpus/outputs`. Already-scored clips are
  skipped (0 credits), so adding or fixing clips only bills the new ones (`--only <ids>`).
  Use `--latency-ids <9 stratified base_ids>` for the recommended run (quality on all 145,
  latency only on the 45-clip subset ≈ 42k credits vs 80k for latency-everywhere).
  `--dry-run` prints the cost with no synthesis.
